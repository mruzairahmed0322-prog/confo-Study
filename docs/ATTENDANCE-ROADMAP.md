# Attendance — Upcoming Features (Private Roadmap)

> Owner-only notes. **Not shown in the app UI.** Implement when ready.

Roadmap window: **2026–2027**

## Q4 2026

| Feature | Notes |
|--------|--------|
| **QR Check-in** | Students scan a daily QR at the gate or classroom for instant attendance. |
| **Parent SMS Alerts** | Auto SMS/WhatsApp to parents when a child is marked absent or late. |
| **Offline Kiosk Mode** | Mark attendance without internet; sync when back online (IndexedDB / local queue). |
| **Substitute Teacher Mode** | Temporary secure access for substitutes to mark class attendance. |

## Q1 2027

| Feature | Notes |
|--------|--------|
| **Biometric Kiosk** | Fingerprint / face at entrance; offline sync then auto-upload. |
| **Student Self Check-in** | Mobile app arrival confirm with geo-fence validation. |
| **Geo-fenced Attendance** | Verify staff/student location when marking from mobile. |

## Q2 2027

| Feature | Notes |
|--------|--------|
| **AI Attendance Insights** | Predict chronic absenteeism; suggest interventions before rates drop. |
